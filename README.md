# express-jwt-rbac-starter

Express.js REST API boilerplate with JWT authentication, refresh tokens, and Role-Based Access Control.

`#nodejs` `#express` `#jwt` `#rbac` `#security`

## Highlights
- Modular, clean architecture
- Documented API and straightforward integration
- Tested for performance and stability

## Quick Overview
```
// Express server entry point
const express = require("express");
const app = express();
app.get("/health", (req, res) => res.json({ status: "healthy" }));

```
